# Registro Strumenti & Script di Utilità (/Tools)

Questo registro documenta gli script di automazione e verifica presenti nella cartella `/Tools`.

| File | Scopo | Utilizzo |
| :--- | :--- | :--- |
| `check_line_limits.py` | Esegue la scansione di tutti i file del repository (`.py`, `.js`, `.jsx`, `.css`, `.html`) verificando che nessuno superi il limite invalicabile delle 100 righe (avviso da 90): richiama lo strumento unico di AI-hub (`tools/check_line_limits.py`, hub in `AI_HUB_PATH`); regole in `.linelimits`. | `python Tools/check_line_limits.py` |
| `check_i18n_keys.py` | Esegue l'audit statico di tutte le chiamate `t('...')` in JSX e JS, garantendo che ogni singola chiave esista e si risolva sia in `it` che in `en`. | `python Tools/check_i18n_keys.py` |
| `test_logic.py` | Esegue i test unitari automatizzati sulle formule del bilancio (Sinking Funds, quota mensile, moltiplicatori di frequenza) e sulla completezza speculare dei dizionari i18n (`it.json` e `en.json`). | `python Tools/test_logic.py` |
| `test_dates.mjs` | Test delle scadenze ricorrenti (`src/core/dates/recurrence.js` e helper spese/bilancio): mensili, fine mese, bimestrali/trimestrali, custom giorni/mesi, `endDate`, `excludedDates`, una tantum, 29/02, scadenza di oggi. I casi di storico all'indietro e controllo chiavi `installments` stanno in `test_dates_history.mjs` (caricato dal runner). Si riesegue da solo con `TZ=Europe/Rome` e `TZ=America/New_York`; exit code 1 se fallisce. | `node Tools/test_dates.mjs` |
| `test_notifications.mjs` | Test delle notifiche/scadenze imminenti (`upcomingHelper.js`, `notificationDismissal.js`): scaduti entro 60 gg, finestra `alertDays`, `enableAlert`, id per occorrenza, migrazione e pulizia degli id nascosti (anche dopo "Annulla"). I casi dell'export calendario `.ics` (RRULE, VALARM, CRLF, piegatura a 75 ottetti) stanno in `test_notifications_ics.mjs`, quelli del preavviso per spesa (`alertDays`, predefinito globale) in `test_notifications_alert.mjs` (entrambi caricati dal runner, non si lanciano da soli). Si riesegue da solo con `TZ=Europe/Rome` e `TZ=America/New_York`; exit code 1 se fallisce. | `node Tools/test_notifications.mjs` |
| `test_profiles.mjs` | Test degli elementi senza profilo (`src/core/profiles/orphanItems.js`): rilevamento di spese/documenti con profilo vuoto o inesistente, profilo iniziale del form, assegnazione. Exit code 1 se fallisce. | `node Tools/test_profiles.mjs` |
| `test_system_notifications.mjs` | Test delle notifiche di sistema (`public/sw-notify-core.js`, `src/core/notifications/`): selezione dal mirror, riassunto, una notifica per fase (in arrivo/oggi/in ritardo), registro "già notificato", silenzioso. Si riesegue con `TZ=Europe/Rome` e `TZ=America/New_York`. | `node Tools/test_system_notifications.mjs` |
| `test_demo_data.mjs` | Test del riconoscimento dei dati di esempio (`src/components/onboarding/demoCompare.js`): banner solo con dati identici agli esempi, "Rimuovi gli esempi" toglie solo le voci di esempio mai modificate e conserva profili con voci o impostazioni dell'utente. Exit code 1 se fallisce. | `node Tools/test_demo_data.mjs` |
| `launch_with_qr.py` | Rileva l'indirizzo IP locale (anche sotto hotspot dati mobili), genera e stampa un QR Code ASCII su terminale per collegarsi da smartphone e avvia il server Vite in ascolto su rete locale. | `python Tools/launch_with_qr.py` |
